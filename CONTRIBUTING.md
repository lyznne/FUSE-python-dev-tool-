# Contributing to FUSE

Thanks for your interest in contributing to FUSE!

We welcome pull requests, bug reports, documentation updates, and feature ideas.
Please read the guidelines below to ensure a smooth collaboration.

---

## 📦 Development Setup

1. Fork the repository
2. Create a feature branch
3. Write your code and tests
4. Submit a PR with a clear description

---

## 🧾 Contributor License Agreement (CLA)

By contributing to FUSE, you agree that:

- Your contributions are your original work, and
- You allow your contributions to be licensed under the terms of both:
  - the AGPL-3.0 license, and
  - a future **commercial license** maintained by the FUSE maintainers.

This ensures that the project can stay free and open, while enabling a sustainable commercial path.

If you're contributing on behalf of a company, make sure you're authorized to do so.
